# FetalCardio

Учебное PWA-приложение по фетальной эхокардиографии: стандартные срезы со схемами, алгоритмы «от находки к диагнозу», атлас ключевых ВПС, тест.

Автор: Жумагулов Н.М., врач ультразвуковой диагностики.

Сайт: https://jumagulovnm2016-ai.github.io/fetalcardio/

## Структура

| Файл | Что внутри |
|---|---|
| `data/meta.js` | Название, версия, автор, категории пороков |
| `data/views.js` | Стандартные срезы |
| `data/algorithms.js` | Алгоритмы «от находки к диагнозу» |
| `data/pathologies.js` | Карточки ВПС |
| `data/quiz.js` | Вопросы теста (`a` — номер верного варианта, счёт с 0) |
| `data/references.js` | Реестр источников (организация, название, год, DOI/URL, PMID) |
| `validate.js` | Схема контента и валидатор (браузер + Node) |
| `search.js` | Поиск: ё/е, регистр, синонимы, аббревиатуры, все поля |
| `progress.js` | Экспорт/импорт прогресса в JSON |
| `schemes.js` | SVG-схемы срезов |
| `app.js`, `style.css`, `index.html` | Интерфейс |
| `sw.js`, `manifest.json` | Офлайн-режим и установка |
| `tests/` | Автоматические тесты |

## Медицинский контент

- Все срезы, алгоритмы и карточки имеют `status: "draft"` до экспертной проверки.
- `status: "approved"` валидатор принимает только вместе с `reviewedBy` и `reviewedAt` (ГГГГ-ММ-ДД).
- Источники в карточках пока указаны на уровне всей карточки (`section: "card"`, `verified: false`): это документы по теме, их соответствие конкретным утверждениям не сверено. После сверки укажите конкретный раздел (`def`, `keys`, `ddx`, `assoc`, `pitfalls`, `prognosis` …) и `verified: true`.
- Каждый источник в `data/references.js` сверен с записью PubMed (PMID и DOI).

## Проверка

```bash
npm test                       # контент, ссылки, ID, ответы теста, поиск, прогресс, SW
npm run validate               # только проверка контента
python3 -m http.server 8765 &  # затем браузерная проверка (нужен Playwright):
python3 tests/e2e.py           # все страницы × 3 ширины × 2 темы, офлайн, экспорт/импорт
```

Перед публикацией изменений контента запускайте `npm test`. При изменении списка файлов обновите `FILES` и `VERSION` в `sw.js`.
