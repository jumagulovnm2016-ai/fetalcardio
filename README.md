# FetalCardio

Учебное PWA-приложение по фетальной эхокардиографии: стандартные срезы со схемами, алгоритмы «от находки к диагнозу», атлас ключевых ВПС, тест.

Автор: Жумагулов Н.М., врач ультразвуковой диагностики.

## Структура
- `data.js` — весь контент (срезы, алгоритмы, пороки, вопросы). Редактируется без знания программирования.
- `schemes.js` — SVG-схемы срезов.
- `app.js`, `style.css`, `index.html` — интерфейс.
- `sw.js`, `manifest.json` — офлайн-режим и установка на телефон.

## Проверка контента
У каждой карточки порока есть поле `status`. После личной проверки замените `"draft"` на `"approved"` — плашка «черновик» сменится на «проверено автором».
