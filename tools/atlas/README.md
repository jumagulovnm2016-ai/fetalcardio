# Генератор схемы атласа 4CV

`atlas/4cv-normal.svg` собирается скриптом, руками SVG не правится.

- `build_svg.py` — геометрия (координаты камер, перегородок, клапанов) и подписи 1–17.
- `build_4cv.py` — отрисовка в объёмном стиле, неровный трабекулярный край желудочков; версия 4 — стиль медицинской иллюстрации (синие правые / красные левые отделы, светлый миокард с фактурой, тушевой контур), укороченные предсердия, без выносок: номера на структурах (`MARKS`), расшифровка и подсказка `<title>` — по номеру.

```bash
pip install svgpathtools numpy matplotlib
cd tools/atlas && python3 build_4cv.py ../../atlas/4cv-normal.svg
```

После сборки: `npm test` и `python3 tests/e2e.py` (проверяют подписи, слои и анатомические соотношения).

## Схемы нормы остальных срезов

`build_views.py` собирает `situs-normal.svg`, `lvot-normal.svg`, `rvot-normal.svg`, `3vv-normal.svg`, `3vt-normal.svg`
в том же стиле (номера на структурах, расшифровка — в `data/anatomy.js`). LVOT (версия 2) — поперечный срез: сердце рисуется в апикальной системе
и поворачивается на 45° (ось влево), аорта продолжает линию МЖП; все схемы — поперечный срез туловища
с рёбрами, позвонком, лёгкими/органами живота.

```bash
cd tools/atlas && python3 build_views.py ../../atlas
```

Номера и ключи структур берутся из списков `M` в каждой функции — при изменении обновите `structures` в `data/anatomy.js`.

## Схемы пороков

`build_chd.py` собирает схемы ВПС на основе схем нормы (те же стиль, слои и номера):
КоА (3VT, сагиттальный срез дуги), СГЛОС (4CV, 3VT), АВСД, Эбштейн, ТАДЛВ, ккТМА (4CV),
ТФ, ОАС, ТМА, DORV, стеноз АК (LVOT), ТФ и ТМА (3VV), стеноз ЛА (RVOT), правая дуга (3VT), правый/левый изомеризм (situs).

```bash
cd tools/atlas && python3 build_chd.py ../../atlas            # все схемы
cd tools/atlas && python3 build_chd.py ../../atlas coa-3vt    # одна схема
```

Номера и ключи — в списках `M` каждой функции; легенда в `data/anatomy.js` должна с ними совпадать (проверяет `npm test`).
